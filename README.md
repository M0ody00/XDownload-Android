# X Player Pro 3.0 Preview 1
Separate package com.xplayer.pro, Android 6+ target. Based on working Lite 2.0, adds nested settings, persisted favorites/history, folder exclusions, optional thumbnails, autoplay/resume/seek options, subtitle styling, resize modes, screen lock, A-B repeat, sleep timer, shuffle-one selection, audio effects when device supports them, and manual network playback via Media3 HLS/DASH/RTSP. Network permissions used only for user-supplied URLs; HTTP initially blocked by UI (redirects not guaranteed blocked). This is a partial implementation, not full parity. Still missing background MediaSession service, LibVLC/SW codec pack, automatic subtitles and offset, audio sync, SMB/NAS/DLNA/Cast, TV/Auto, screenshot/cut/export, editable playlist management, file mutations, PIN/biometrics, backup, full multilingual themes, and physical device validation. Nine CI tests cover sample playback, library discovery, preferences and settings navigation; other added functions need manual verification. Debug signing, not production.
