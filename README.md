# X Download Pro 1.0 RC1
Native Java Android 10+ app for authorized direct HTTP(S) files. Independent package, no native ABI libraries. URL analysis (name, MIME, size when available), sequential resumable queue, validator checks, retry, pause/cancel, foreground notification, Wi-Fi/battery constraints, rate-limited modes, bulk links, system share, WebView with no local-file access or JS bridge, official site shortcuts, categorized MediaStore output, SHA-256 verification, APK metadata inspection (not malware detection), light/dark, Arabic/English navigation, settings backup and diagnostics. No ads/analytics.
Limits: sequential not multiconnection; no automatic reconnect after service stops; no native streaming-site integrations, DRM, conversion, vault, archive extraction, Wi-Fi transfer, scheduler, multitab/incognito, cookie handoff. Smart and Turbo use same unlimited rate. Source quality only. Requires temp and final storage. CI debug key not persistent; protected signing environment variables supported but not configured. Eight local HTTP unit tests and real Android transfer test on API 30/35 targeted; not exhaustive. Developer & Owner: Ahmed Nasr (original code/design).
Hardening: explicitly reject streaming manifests, preserve completed partial on verified 416, restart safely when validator absent, discard checksum mismatch, classify generic MIME by extension, make job UI fields visible across threads. Ten JVM tests targeted; hardware still untested.
RC2 work: Turbo attempts three parallel validated ranges only for fresh files with strong ETag and enough storage; falls back to sequential retry. Interrupted parallel segments restart rather than being treated as a contiguous partial. Network policy waits and short schedules work while foreground service survives, up to one hour; not exact alarms, cannot bypass OS force-stop or battery restrictions. Sequential job queue (not simultaneous independent file transfers).
RC2 local tools: password-encrypted AES-GCM files (64 MiB limit; no biometric/keychain vault), authenticated decryption before export, ZIP extraction with traversal and expansion checks, MP4 H.264/AAC conversion/trim, M4A/MP3 extraction via the previously used Media3/FFmpeg components. WebView lists explicit HTML download links, not protected stream extraction. These additions require build and test verification. Video merge/compression, audio merge, format breadth, multi-tab/private mode and local Wi-Fi sharing not implemented.
RC2: up to four regular WebView tabs; limited private HTTPS browser in separate process with cookies, DOM storage, JavaScript and cache disabled, cleanup on close. Not anonymity, and private mode may not support modern interactive sites. Added parallel range round-trip and fallback tests; stale notification actions bind to the original job ID.
RC2 includes explicit 720p resize (not guaranteed smaller output), local one-file Wi-Fi transfer on trusted private IPv4 Wi-Fi (unencrypted HTTP, random expiring token, one GET, stops on leaving screen), plus native MP3 encoder instrumentation test. No private signing secret has been configured; release signing still requires owner-controlled secret. Neither full arbitrary media format support nor any protected-platform download is claimed.
Added two-file sequential merge for supported video (MP4) or audio (M4A), using Media3 1.5.1 composition API. Added synthetic audio merge duration test. Input codec/device support and all current CI results still need verification.
