# X Player Lite 2.0
Personal offline Android media player. Minimum API 23. MediaStore library with automatic discovery, video/audio/all tabs, folder grouping, search, sorting, video thumbnails on API 29+, auto refresh, next/previous, details and share. Requires read media permission. MediaStore only shows indexed and permitted files, not private app folders or all unindexed formats; manual picker remains available. No internet permission. Android platform decoders plus Media3; not an exact MX Player clone, no bundled SW codec pack, background playback service or full parity. New package com.xplayer.lite.library allows installation beside v1 without debug signing conflict. CI verifies six playback samples and one device library discovery test on API 30 and 35 before publishing. Physical OPPO device testing is still required.
