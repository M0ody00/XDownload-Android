# X Player Pro 3.0 Preview 2
Based on preview 1. Added optional user-selected LibVLC 3.6.1 playback (hardware/software; retry from error dialog, audio and subtitle offsets, external subtitle picker), direct SMB/FTP/SFTP/NFS URL routing, separate MediaSessionService for background playback with system media controls, local video trimming and AAC audio export via Media3 Transformer (M4A, NOT MP3). These are newly implemented and require verification. Bundles native VLC libraries, increases size substantially. LibVLC source/build instructions: https://code.videolan.org/videolan/libvlcjni and https://github.com/videolan/vlc-android ; see upstream LGPL/GPL notices and source obligations before distributing. Media3 Apache-2.0. Personal test build; not a distribution-ready licensed release. Existing preview1 features retained. Remaining: MP3 transcoder, Cast/DLNA discovery, actual file/folder protection, full themes/languages, backup and editable playlists until next commit. No physical OPPO tests.
