# X Player Pro 3.0 Preview 3
Separate preview app. Android 7+ due to MP3 library requirements. Includes previous settings and library, LibVLC HW/SW and audio/subtitle offsets, background MediaSession service, local trim/M4A and FFmpegKit MP3 export, named editable playlists, JSON settings backup/restore, accent selection and partial English navigation, in-app hiding of selected folders gated by device authentication (not encryption or OS-wide access control), LibVLC network browsing and renderer discovery for compatible SMB/UPnP/DLNA/Chromecast devices. External device compatibility, actual fingerprint authentication, full English localization and advanced playback UI interactions are not established. Native library support varies by ABI; MP3 requires compatible FFmpeg native binaries. CI checks 14 tests: original sample playback, library discovery, settings and favorites, playlist/backup, VLC playback, MP3 output MIME, background playback with the activity stopped, and trimmed MP4 duration. Does not validate every feature. Physical device and network receiver tests required. LibVLC 3.6.1 upstream https://code.videolan.org/videolan/libvlcjni ; FFmpegKit audio 8.1.7 community fork https://github.com/ffmpegkit-maintained/ffmpeg ; source/license obligations must be reviewed before any wider distribution. Media3 Apache-2.0. Personal test build only.

## RC1 remediation
Explicit smart-exception-java 0.2.1 dependency addresses observed MP3 NoClassDefFoundError. Keeps known compiling Media3 and FFmpeg versions for controlled regression; newer versions require independent migration and security review. Adds decoder-error-triggered VLC retry, continuous random next selection, background queue handoff, screenshot capture via PixelCopy, orientation toggle, audio virtualizer if supported, Android 11+ MediaStore rename/trash with system confirmation, bounded thumbnail queue, stale network event guard and export cleanup. ARM64 package built using the same debug signature as universal APK and inspected for native libraries; emulator tests apply to universal x86_64, NOT ARM64 hardware. No final release claim. Unimplemented: secure encrypted vault, fully unified VLC UI, optional downloadable codec packs, complete bilingual/day mode, unindexed folder scanning, automatic subtitle discovery/download, TV/Auto, remote access, complete network and cast verification, album artists/cover management, all-formats or battery performance assurance.

RC2 adds explicit Storage Access Framework tree scanning, including hidden/unindexed files that the selected provider exposes; capped at 10,000 entries and depth 32 per tree. Same-name SRT/ASS/SSA/VTT discovery in selected trees. Lite mode disables video thumbnails and persistent screen-on and slows the timer polling outside A-B mode. No broad storage permission, no external service. A media file can appear twice if indexed and also selected via SAF; this is not yet deduplicated. Some providers disallow selection of roots or protected folders. Adds one extension classification test (not a real external USB test). 15 tests per emulator.
